# D2 Survivors 打工仔 發行檔

**下載整合包（桌面版＋網頁版）：** 到 [Releases](https://github.com/s159735/D2Survivors-ZH-Autoplay-Release/releases/latest) 下載最新的「D2 Survivors 中文化+自動控制 v版本.zip」。

裝過 v0.9.8 以上的整合包之後，之後在打工仔面板標題列按「更新」→「立即更新」就能換到新版，不用再下載。

這裡的檔案是打工仔面板「更新」按鈕的下載來源：`latest.json` 是更新清單，`latest.json.sig` 是作者的數位簽章，`v版本/` 是該版的打工仔檔案。打工仔只接受簽章正確、檔案雜湊相符、版本比目前新的更新；請勿手動修改這些檔案。

本存放庫只含打工仔（自動控制）；中文化由原作者另外維護與更新，不在這裡。
